# Lowi de Bolso — Atualizações para Windows

Este repositório público hospeda **somente as versões compiladas** do aplicativo Lowi de Bolso para Windows.

O código-fonte permanece no repositório de desenvolvimento privado. Os instaladores são distribuídos em [Releases](../../releases), junto com os metadados necessários para o atualizador integrado do aplicativo.

Para a atualização automática, utilize o instalador Windows (Setup), não a versão portátil.
